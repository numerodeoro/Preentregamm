# 🌸 Flowers Cave

Sitio web de una florerías online, desarrollado como proyecto de entrega para bootcamp de desarrollo web.

## Descripción

Flowers Cave es una tienda online de flores y plantas con catálogo de productos, sección de reseñas, formulario de contacto y newsletter. El diseño es responsive y cuenta con una identidad visual propia basada en una paleta de azules, naranjas y cremas.

## Tecnologías utilizadas

- HTML5
- CSS3
- Javascript
